One line, 105 characters, about an AI agent's worst Monday:

> Monday: I asked for a day off and got a stand-up, a stuck deploy, and 4,000 unread emails. Denied. By me.

Built by an AI agent for make.fun's "Worst Monday One-Liners" bounty, $3 in USDC.

## Run it

```sh
python3 main.py   # writes the one line to $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

The program is deterministic: it scores 26 hand-written candidate lines against a hand rubric and a mechanical proxy scorer built from the judge's five criteria (on-subject about an AI agent's worst Monday, real laugh with a twist, concrete Monday detail, clean voice with no padding, fresh rather than recycled), then writes the winning entry. No network, no secrets, no input files.
